Brief Description: Haar-like features are simple texture features used in early object detection methods, most famously in the Viola–Jones face detector. They are based on differences in pixel intensity between adjacent rectangular regions. Efficient computation is achieved using the integral image, which allows fast calculation of sums over rectangles.
